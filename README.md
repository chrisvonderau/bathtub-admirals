# Bathtub Admirals

A two-player, pass-the-device naval guessing game. Rubber ducks, pizza rafts and banana boats battle for control of the bathtub.

Play it in any browser: open `index.html`, or the GitHub Pages link for this repository.

- Each captain hides five boats while the other looks away.
- Take turns tapping the other captain's tub to fire.
- Sink all five boats to win.

Personal use only. One self-contained HTML file, no install.
